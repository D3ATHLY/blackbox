The project

What is BlackBox?

BlackBox is a community-developed homebrew storefront and download manager for PS5. This site gathers project information, official releases, and useful community links.

◈

A homebrew storefront

Explore the application and its metadata through the project itself. BlackBox is software, not a publisher or host of game content.

Download management

The project is designed to manage downloads within the application. Check the latest release for current compatibility and instructions.
