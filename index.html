The project

What is BlackBox?

BlackBox is a community-developed homebrew storefront and download manager for PS5 consoles. This page brings together official project information, release links, and support resources.

◈

A homebrew storefront

Explore the application’s features and metadata through the project’s own interface. BlackBox is software—not a publisher or host of game content.

↻

Download management

The project is designed to help manage downloads within the application. Availability and compatibility can change; consult the release notes for current details.
